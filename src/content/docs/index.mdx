WildBridge is an open-source Android application (Kotlin, DJI Mobile SDK V5) that runs on the DJI Remote Controller and exposes drone telemetry, control, and video streaming over a local Wi-Fi network. Any ground station that can speak HTTP, TCP, or MAVLink 2 can fly a DJI drone — no DJI SDK required.

![WildBridge System Architecture](../../../docs/images/WildBridgeDiagram.png)

*Multi-drone setup: each RC runs WildBridge and exposes HTTP commands (port 8080), TCP telemetry (port 8081), discovery, and WHIP/WHEP video publishing through MediaMTX.*

## Why WildBridge?

<CardGrid stagger>
	<Card title="Protocols, not SDKs" icon="terminal">
		REST commands, streaming JSON telemetry, a full MAVLink 2 vehicle, and WHIP/WHEP video. Integrate from Python, ROS 2, QGroundControl, MAVSDK — anything.
	</Card>
	<Card title="Multi-drone by design" icon="rocket">
		Several aircraft coexist on one LAN. Auto-discovery finds each drone, and ROS namespaces follow the drone's own name.
	</Card>
	<Card title="Two-computer safety" icon="setting">
		A Safety Computer can seize command authority from the Pilot Computer at any time, and only it can hand control back.
	</Card>
	<Card title="Mission-proven" icon="open-book">
		Zebra herd monitoring, wildfire detection (XPRIZE Wildfire semi-finalist), and wind-field profiling.
	</Card>
</CardGrid>
